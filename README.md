# Structs - Exercícios (Nível Médio)

Exercícios 5 a 9 da lista de Structs da disciplina de Algoritmos e Programação (4188), Ciência da Computação, UNIVALI.

## Exercícios

| Arquivo | Descrição |
|---|---|
| `exercicio05_data.cpp` | Leitura de uma data com struct e função que verifica se ela é válida, considerando anos bissextos |
| `exercicio06_trocar.cpp` | Função template `trocar` usada com `int` e com a struct `Ponto` |
| `exercicio07_pessoas.cpp` | Cadastro de até 10 pessoas com data de nascimento gerada automaticamente, listagem de idades e de pessoas mais velhas que uma idade informada |
| `exercicio08_maior.cpp` | Função template `maior` usada para achar a maior nota de uma turma de 30 alunos |
| `exercicio09_livros.cpp` | Struct `Livro` e função que conta quantos livros têm mais páginas que um valor informado |

## Como compilar e executar

```bash
g++ exercicio05_data.cpp -o exercicio05
./exercicio05
```

O mesmo vale para os outros arquivos, trocando o nome.
